# DB 마이그레이션 안내

마이그레이션은 다음 순서로 적용합니다.

```text
V1 → V2 → V3 → V4 → V5 → V6 → V7
```

V4~V6은 youngtak 브랜치에서 추가한 여행 날짜 및 태그 관련 변경이며 그대로 유지했습니다.

V7에는 관리자 기능에 필요한 다음 변경만 추가했습니다.

- 사용자 역할 및 계정 상태
- 게시물 관리 상태
- 신고 데이터
- 수정하지 않고 계속 누적하는 관리자 감사 기록

## 로컬 시연용 관리자 계정

```text
이메일: admin@journey-connect.local
비밀번호: Admin1234!
```

이 계정은 로컬 발표 데이터 전용입니다. 공용 서버나 실제 배포 환경에 적용하기 전에 반드시 교체해야 합니다.
