# DB v1.2 누적 리뷰

## 보완 반영

- 대표 지역과 게시글 장소의 계층 일치 검증 추가
- 지역 순환 참조 차단 추가
- 부모·자식 지역의 국가 코드 불일치 차단
- 국가 지역은 루트에만 존재하도록 제약 강화
- 지역 계층 변경으로 기존 공개 게시글이 오염되는 경우 차단
- 이미지 URL 전역 UNIQUE 제거
- 삭제 시점을 외부에서 임의 조작하지 못하도록 생명주기 트리거 강화
- 장소 좌표 검색용 부분 인덱스 추가
- 스모크 테스트에 실패 케이스 검증 추가

## 설계 판정

현재 확정된 기능 범위에서 필요한 데이터만 포함합니다. AI, 루트, 크루 등의 미확정 기능을 위한 테이블은 만들지 않았습니다.

## 남은 운영 정책

다음은 DB 결함이 아니라 백엔드 또는 운영 정책으로 결정할 항목입니다.

- 회원 탈퇴 시 콘텐츠 익명화 여부
- 실제 이미지 파일 삭제 방식
- 장소 중복 후보를 사용자에게 표시하는 방식
- 조회수 중복 방지 기준
- 삭제 게시글 영구 삭제 함수 실행 주기

## 실행 검증 범위

SQL 구조와 상호 참조를 정적 검토했고, `03_smoke_test.sql`에 핵심 정상·실패 시나리오를 포함했습니다. 현재 환경에는 PostgreSQL 서버가 없어 실제 서버 실행 결과까지 확인한 것은 아닙니다.


## v1.2 보완 반영

- 국가 루트(`region_type = 'country'`)의 `country_code`에 부분 UNIQUE 인덱스를 추가했습니다.
- 기존 `UNIQUE (post_id, sort_order)`와 중복되던 `post_images_post_id_idx`를 제거했습니다.
- 하위 지역 Seed의 `ON CONFLICT` 갱신 범위를 전체 관리 컬럼으로 확장했습니다.
- Smoke Test의 테스트 국가 코드를 `ZZ`, `YY`로 분리했습니다.
- 동일 국가 코드의 국가 루트 중복 삽입이 실패하는지 Smoke Test에 추가했습니다.
